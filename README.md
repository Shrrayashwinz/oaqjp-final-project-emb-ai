# e-plantShopping

## Project Overview
This project is part of the IBM / Coursera “Python Project for AI Application Development” course.  
The repository contains the files used to build an Emotion Detection web application using Python, Flask, and the Watson NLP EmotionPredict API.

## Application Description
The application sends user‑provided text to the Watson NLP EmotionPredict service and returns the detected emotions.  
It includes:
- A Python module (`emotion_detection.py`) that calls the Watson NLP API  
- A Flask web application that exposes an emotion detection endpoint  
- An HTML interface for users to enter text and view results  

## Folder Structure
- `final_project/` – Contains all project files  
  - `emotion_detection.py` – Emotion detection function  
  - `server.py` – Flask application  
  - `static/` – CSS files  
  - `templates/` – HTML UI
